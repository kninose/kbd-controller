# kbd-controller

## Specifications
- Size: 300 x 100 mm
- KeySwitch: Cherry MX or Kailh Choc V2
- MicroController: Raspberry Pi Pico
- ScrewHole: M2

## KiCad Libraries
- Symbols: https://github.com/kninose/KiCad-Library/tree/main/Symbols
- Footprints: https://github.com/kninose/KiCad-Library/tree/main/Footprints
